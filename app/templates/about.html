About KrishiSahayak

Bridging the gap between real-time agricultural data and Nepali farmers through localized intelligence, weather risk forecasting, and LLM-driven advisories.

🌤️

Weather Risk Tracking

Integrated directly with live meteorological engines (Open-Meteo) to provide multi-day temperature, wind, and rain probability forecasts across major agricultural hubs like Kathmandu, Pokhara, Chitwan, and Biratnagar.

📈

Kalimati Market Intelligence

Tracks daily wholesale commodity pricing benchmarks for essential crops like potatoes, tomatoes, onions, and cauliflowers, helping farmers decide when and where to sell for maximum profit.

⚡

LLM Agent Tool Routing

Powered by a FastAPI backend with structured function-calling routers that automatically translate natural language farmer questions into precise API queries.

🛠️

Modern Tech Stack

Built using Python, FastAPI, Uvicorn, Jinja2 templates, Tailwind CSS, and `httpx` for high-performance asynchronous execution and cross-device responsiveness.
